🌐 **Live:** https://www.petmets.in/

### 🧠 [SynapseFlow](https://github.com/PuneetShivaay/SynapseFlow)
An in-progress **graph-first AI agent SDK in TypeScript** exploring graph-native memory, event-driven architecture, agent orchestration, tool execution, guardrails, and observability.

### 🔎 [CourseAI](https://github.com/PuneetShivaay/CourseAI)
An **Advanced RAG** system for searching SRT/VTT course subtitles and returning grounded answers with **lesson and timestamp citations**. Implements retrieval patterns including **HyDE, Step-Back Prompting, Parallel Query Fan-Out, and Reciprocal Rank Fusion (RRF)** using OpenAI and Qdrant.

### 🤖 [Deep Learning Chatbot for Medical Assistance](https://github.com/PuneetShivaay/Deep-Learning-Based-Chatbot-For-Medical-Assistance)
A Python deep-learning chatbot project that maps user-provided symptom inputs to possible disease classes using an artificial neural-network-based model.

⭐ **17 stars** · 🍴 **14 forks**
